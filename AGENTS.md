# AGENTS.md

## Project Context

This repository contains the Lemon Logistics website. Keep changes focused on the requested task and preserve the existing project structure, design system, routes, and deployment behavior.

## Key Files

- `src/`: frontend application source.
- `src/pages/`: page-level components.
- `src/components/`: reusable UI and layout components.
- `src/lib/`: site data, translations, and shared utilities.
- `api/`: serverless API handlers.
- `public/`: static assets.

## Working Notes

- Use `npm run dev` for local frontend development.
- Use `npm run build` to verify production builds.
- Do not commit secrets or local environment files.
- Reuse existing components and styles before introducing new patterns.
- Keep the public site lightweight and avoid adding unnecessary runtime dependencies.
